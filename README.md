# 🏦 PersonalFinanceTracker

## 📌 Description
PersonalFinanceTracker is a command-line personal finance management application written in C++. It allows users to record income and expenses, organize expenses by category, and store financial data in an SQLite database.
## 🚀 Features
- Add income and expenses.
- Monthly reports.
- Spending categories.

## ⚙️ Installation
```bash
git clone https://github.com/AnnaFilimon-ova/PersonalFinanceTracker.git
cd PersonalFinanceTracker
cmake -S . -B build
cmake --build build
./build/FinanceTracker  
```

## ▶️ Usage
After running the project, follow the instructions in the terminal.

## 🛠 Tech Stack
- C++
- CMake
- SQLite
- GoogleTest
